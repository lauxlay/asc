# Vision & positionnement

> Statut : draft

## Vision

Devenir la plateforme de référence qui connecte les trois acteurs de la vie d'un ascenseur — l'ascensoriste (PME de maintenance), le donneur d'ordre (syndic / copropriété / particulier) et le technicien terrain — autour d'une source de vérité unique : le parc, les visites, les pannes, le carnet d'entretien.

## Problème

Le marché est coincé entre deux mondes :

- **Progilift** : très métier ascensoriste (normes FR, SAV, facturation) mais UX datée, pas de portail client moderne, peu ouvert (API), mono-persona (l'ascensoriste).
- **Praxedo** : excellent field service généraliste (planning, optimisation tournées, mobile) mais pas métier ascenseur (pas de carnet d'entretien réglementaire, pas de contrat minimal/étendu, pas de contrôle quinquennal), offline limité, intégrations fermées, licences rigides.

Personne ne sert le côté **client final** : le syndic / conseil syndical n'a aucune visibilité sur la réalité des visites (pain point documenté : visites réglementaires non réalisées, carnet non rempli).

## Positionnement

**« Le Progilift moderne, avec le planning de Praxedo, et un portail client que le syndic adore. »**

Trois différenciateurs :

1. **Métier ascenseur natif** : contrats types (minimal / étendu, arrêté du 7 novembre 2012), visites toutes les 6 semaines, contrôle technique quinquennal, carnet d'entretien numérique opposable.
2. **Transparence client** : portail copro/syndic avec preuve de passage (géoloc + horodatage + photos), historique pannes, taux de disponibilité par appareil.
3. **Ouvert et moderne** : API publique, offline-first mobile, tarification par siège flexible (licence technicien allégée).

## Marché cible (France d'abord)

- ~640 000 ascenseurs en France, obligation légale de contrat d'entretien.
- Cible primaire : PME ascensoristes indépendantes (hors Otis/Kone/Schindler/TK qui ont leurs outils internes).
- Cible secondaire : syndics et gestionnaires de parc (offre de supervision).
- Extension : portes automatiques, escaliers mécaniques, contrôle d'accès (mêmes acteurs).

## North star metric

Nombre d'appareils sous contrat gérés dans la plateforme.
